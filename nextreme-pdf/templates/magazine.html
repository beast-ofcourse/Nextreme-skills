Every event a node, every join an edge — the medium that was missing.

Tables ask you to know the question in advance. Graphs let you ask the question you didn’t know to ask. At 1.2B events per day, the batch report’s 6-hour latency isn’t a bug — it’s the medium. Flux replaces tables with a graph: events as nodes, joins as edges. Any query is a subgraph, not a migration. The paper on page 3 shows the cut: 6.0h → 4.1m p95, cost −22%, zero broken contracts in 18 months.

The editorial system matters: warm cream `#fffbf5`, Lora for body, Cormorant for heads, `hyphens: auto` and `text-wrap: pretty` so rivers never form. Photos thread around text via meander — diagonal placements, not stacked blocks. This spread is the proof.

Design is intelligence made visible — now at data scale.

— Flux principle #3
